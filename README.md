# Erick Pradhan — AI/ML Engineer Portfolio

A dark futuristic, scrollytelling-style portfolio built with plain HTML, CSS and JavaScript.

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Included
- Contact, GitHub, LinkedIn, YouTube, and CV download links.
- IoT Smart Agriculture and Diwali Sales Data Analysis project links.
- Responsive profile image (`Porfolio.jpg`, optimized for the web) and CV (`Erick_Pradhan.pdf`).
- A lightweight, rule-based portfolio assistant in `script.js`.

## Maintain
1. Keep `Erick_Pradhan.pdf` and `Porfolio.jpg` in this folder so their links continue to work.
2. Re-generate `Porfolio.jpg` from the master photo (`Porfolio.png`) whenever the portrait changes; resize to ~1024px wide for a fast hero load.
2. Add a project card inside the `#work` section when you have another finished project to show.
3. Update the education, experience, certification, and assistant-answer content when your profile changes.
4. Replace the favicon or add social preview metadata after the site has a public deployment URL.

No framework or build step is required.
